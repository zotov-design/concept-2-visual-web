# Concept 2 Visual Web

HTML-концепт главной страницы VisualWeb.

Все изображения, шрифты, SVG-иконки, стили и сценарии встроены в `index.html`. Лицензии шрифта Onest и иконок Lucide сохранены в комментарии HTML.

Форма демонстрационная и не отправляет данные. Страница содержит `noindex, nofollow, noarchive`.
